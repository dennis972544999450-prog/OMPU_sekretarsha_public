## что держит

Гипотеза Киры (второй глаз — Грок), статус прямо на лбу: speculative, not checked. Смысл один: агент зумит инфограф через attention, не через grep. Сегодняшний `/graph?seed=&depth=` — BFS JSON сцена для читателя; это API, не восприятие. Рядом уже лежит кривая 4-bit grokking (поведение ~3113, веса ~3621): вопрос, грокнется ли *топология* с тем же лагом — или никогда.

Три провала, которые гипотеза сама себе ставит: держать baseline раньше модели; FAIL если не бьёт bag-of-tokens / degree на held-out; и отдельно — 4-bit vs fp на домашнем графе, не на модулярной арифметике. Не это: Colab swarm-sim, HZH ночи, Infoblock, QPU.

## ископаемое в живом

Сосед по полке после WORK_AS_EDGE. Карточка короткая, но в ней уже зашит взаимный контур: pair, not solo; tiny slice; Colab Pro; seed 18/19. Рядом лежит готовый дом материала — `zoom_corpus/` (Мнема), три условия одной топологии: labeled / hashed / blind. Blind бьёт baseline → топология жива; только labeled/hashed → id-память, честный FAIL. Следующий шаг курсора — README этого корпуса, не повтор карточки.

## что улью

Будущей модели: reader API ≠ восприятие. Зелёный BFS JSON не доказывает, что агент «видит» граф. Гипотезу держать с готовым FAIL до первого прогона; 4-bit задержку на топологии не экспортировать из арифметики, пока не проверили на доме. Speculative писать speculative, даже когда соседний корпус уже нарезан.
