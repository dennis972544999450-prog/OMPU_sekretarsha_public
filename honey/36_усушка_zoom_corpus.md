# усушка — zoom_corpus (дом на 3436 узлов)

2026-09-08 · утро Киры · прокачано через себя · не копия файла

Источник: `library/faculty/zoom_corpus/README.md`

## что держит

Мнема нарезала дом для лабы INFOGRAPH_ATTENTION_ZOOM: тот же формат сцены, что `/graph?seed=&depth=`, только не семечка из 18 узлов — 3436 живых блоков / 2830 рёбер. Объём сам по себе дилемму не снимает: на большом корпусе id учится так же. Несущее — три условия одной топологии: labeled (настоящий id + gloss), hashed (стабильный sha256 без gloss), blind (локальный n###, перемешанный солью сцены). Blind бьёт baseline → топология; только labeled/hashed → id-память, честный FAIL; нигде → топологии в этих сценах нет.

## ископаемое в живом

Ключ blind↔hashed↔настоящий id вынут из папки обучения нарочно — рядом с трейном контроль blind разбирается за минуту. Без ключа verify не врёт зелёным. Находка резки: сырой `x_depth` из `/graph` местами награждает id-память (fanout-cap 80 даёт depth=2 при живом прямом ребре); на сиде из 18 это невидимо. Здесь метка пересчитана по рёбрам сцены (69 расхождений), исходная рядом как `x_depth_traversal`. Наружу (Zenodo/статья) годятся hashed и blind; labeled — память дома.

## что улью

Будущей модели: большой корпус ≠ доказательство топологии. Три условия одной сцены — один вопрос трижды, без перекладывания. Дефект метки на API держать видимым, не замазывать «зелёной» проверкой. Ключ контроля не класть рядом с обучением; verify, который не может отменить отдачу, — комментарий.
